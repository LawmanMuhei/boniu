波妞摸鱼 1.8.0 使用说明
=======================

一、运行要求

1. 支持 Windows 10 / Windows 11，提供 x64 和 x86 两种版本；不支持 Windows 7/8/8.1。
2. 双击“波妞摸鱼.exe”（x64）或“波妞摸鱼-x86.exe”（x86），无需安装 Node.js、Electron 或 .NET SDK。
3. 需要 Microsoft Edge WebView2 Runtime 和 .NET Framework 4.8。若提示缺少浏览器运行时，请从微软官网安装 WebView2 Evergreen Runtime，再重新打开程序。
4. 未配置商业代码签名证书时可能显示“未知发布者”。请核对下载来源和 SHA-256；哈希校验不等于发布者身份认证。

二、主要操作

- Ctrl + Alt + D：隐藏或显示整个程序。
- Ctrl + Alt + B：隐藏或恢复顶部工具栏。
- Ctrl + Alt + M：静音或恢复声音。
- Ctrl + Alt + F：进入或退出清爽模式。
- 隐藏时先隐藏窗口，再请求浏览器静音和暂停；不会等待网页脚本完成才隐藏。隐藏约 10 秒后尝试挂起浏览器，若运行时拒绝则稍后重试。
- 鼠标移回原位置不会恢复窗口；使用快捷键、已开启的托盘入口，或重新打开同一程序即可恢复。
- 拖动顶部空白处移动窗口，拖动窗口边缘调整大小。
- 普通窗口和直播窗口分别保存最后的位置与大小。

三、设置与恢复入口

点击顶部齿轮按钮进入设置；点击后退按钮返回视频。

- 隐藏程序、隐藏工具栏、静音和清爽模式快捷键均可自定义；录入时按 Del 可禁用。至少包含一个修饰键，系统保留、与其他快捷键冲突或被占用的组合键不会保存。
- 鼠标移出自动隐藏可关闭，延迟可选择 0.1、0.3、0.5 秒。窗口边缘有防误触缓冲，按住或拖动鼠标期间不会隐藏。老板键和托盘恢复入口都不可用时自动隐藏会停用。
- 失去焦点时隐藏默认关闭；锁屏或本地/远程会话断开时隐藏窗口，不依赖快捷键是否可用。可重新打开程序或使用托盘恢复。
- 可开启“显示托盘恢复入口”；默认关闭，快捷键冲突时为保证可恢复会自动保留。托盘菜单可以恢复窗口、恢复工具栏并打开设置、退出程序。
- 开启直播自动横屏后，直播页和推荐页直播弹层会尝试切换横屏；退出直播后恢复普通窗口。
- 清爽模式保留抖音原生播放器布局，隐藏页面装饰；左导航、顶部搜索和右互动区另有独立开关。
- 检测到清爽布局异常时会回退标准布局并显示提示。可点击提示或设置中的“重新应用页面样式”重试；如果反复回退，建议关闭清爽模式并反馈页面变化。
- 页面加载失败时可点击重试提示；请先检查网络。
- “恢复程序默认设置”不清除抖音登录；“清除登录和网页缓存”需二次确认，无法撤销。

四、更新

启动时检查 GitHub Releases，设置中也可手动检查更新。更新需要用户确认，并经过 SHA-256 校验。
下载中断、超时或校验失败不会替换当前程序；根据提示检查网络、磁盘空间或目录权限后重试。
安装前备份设置和启动器，新版本健康启动检查失败时尝试恢复旧启动器。隐藏时发现更新不会弹出自动确认窗口，可稍后在设置中检查。

五、本地数据与隐私边界

- 登录数据：%LOCALAPPDATA%\MiniViewWebView2\UserData
- 设置：%LOCALAPPDATA%\MiniViewWebView2\settings.json
- 运行日志：%LOCALAPPDATA%\MiniViewWebView2\logs\run.log
- 单 EXE 组件：%LOCALAPPDATA%\MiniViewWebView2\App\1.8.0-<架构>
- 每个架构只保留当前版本和最近一个旧版本的组件；更新前设置备份保留最近三份。
- 沿用 MiniViewWebView2 目录以保留旧版登录和设置。
- 隐藏只是桌面窗口行为，不会从任务管理器、管理员、远程管理、录屏或进程审计中隐身。
- 抖音网页与 WebView2 的数据处理受各自的隐私政策或系统策略约束。

六、退出

点击顶部关闭按钮或托盘菜单“退出”会结束程序。只隐藏窗口不会退出进程。
