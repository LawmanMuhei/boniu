波妞摸鱼 1.6.0 使用说明
=======================

一、运行要求

1. 支持 Windows 10 / Windows 11 64 位，不支持 Windows 7。
2. 直接双击“波妞摸鱼.exe”，不需要安装 Node.js、Electron、Visual Studio 或 .NET SDK。
3. 系统需要 Microsoft Edge WebView2 Runtime 和 .NET Framework 4.8。正常更新的 Windows 10/11 通常已经自带。
4. 程序未购买商业代码签名证书，Windows 第一次运行时可能显示“未知发布者”。请核对文件来源和 SHA-256 后再运行。

二、主要操作

- Ctrl + Alt + D：隐藏或显示整个程序。
- Ctrl + Alt + B：彻底隐藏或恢复顶部工具栏。
- Ctrl + Alt + M：静音或恢复声音。
- 鼠标离开窗口后：程序先立即隐藏，再在后台暂停并静音当前视频。
- 窗口隐藏后，将鼠标移回原位置不会恢复，必须按隐藏/显示程序快捷键。
- 拖动顶部空白处移动窗口，拖动窗口边缘调整大小。
- 程序会分别记住普通窗口和直播横屏窗口最后的位置与大小。

三、设置

点击顶部齿轮按钮进入设置。

- 点击“隐藏/显示程序”或“隐藏/显示边框”的组合键按钮，然后按下新的组合键即可保存。
- 新组合键至少包含 Ctrl、Alt、Shift 或 Win 中的一个修饰键。
- 与另一个快捷键冲突、与 Ctrl + Alt + M 冲突、被系统保留或被其他程序占用的组合键不会保存。
- 开启“直播自动横屏”后，进入直播页或从推荐页手动打开直播弹层时会自动切换横屏，退出直播后恢复普通窗口。
- “鼠标移出自动隐藏”可以关闭，隐藏延迟可选择 0.1、0.3 或 0.5 秒。
- “失去焦点时隐藏”默认关闭；开启后切换到其他程序会立即隐藏。无论该选项是否开启，Windows 锁屏或切换会话时都会隐藏。
- “打开本地数据目录”用于查看本机数据；“恢复程序默认设置”不会清除抖音登录。
- “清除登录和网页缓存”需要二次确认，执行后需要重新登录且无法撤销。
四、直播纯画面

直播状态会隐藏抖音网页顶部主播栏、新旧底部礼物栏和右侧聊天区，并让播放器占满可用区域。抖音网页结构以后发生变化时，可能需要更新适配规则。

五、登录和本地数据

- 登录界面来自抖音官网，程序不读取或上传手机号、密码、Cookie。
- 为保持登录，WebView2 会将 Cookie、会话令牌、LocalStorage 和缓存保存在当前用户本机。
- WebView2 登录数据保存在：%LOCALAPPDATA%\MiniViewWebView2\UserData
- 设置保存在：%LOCALAPPDATA%\MiniViewWebView2\settings.json
- 单 EXE 首次运行会释放程序组件到：%LOCALAPPDATA%\MiniViewWebView2\App\1.6.0-x64
- 继续沿用 MiniViewWebView2 目录是为了保留旧版本的登录状态和设置。

六、隐私边界

波妞摸鱼自身不收集或上传用户信息。抖音网页的数据处理行为受抖音隐私政策约束；WebView2 Runtime 可能按照 Windows 或 Edge 的系统策略发送诊断数据。

隐藏功能只让窗口从桌面和任务栏中消失，不能对系统管理员、任务管理器、远程管理、屏幕录制或进程审计隐藏。

七、退出

点击顶部最右侧的关闭按钮会完全退出程序。只隐藏窗口不会退出进程。
