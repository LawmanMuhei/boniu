# 波妞摸鱼 v1.8.0

> 仅支持 Windows 10 / Windows 11，不支持 Windows 7、Windows 8 或 Windows 8.1。

本版本集中提升老板键隐藏可靠性、自动隐藏体验、页面回退、更新安全和设置界面可用性，并继续提供 x64 与 x86 单文件版本。

## 主要更新

- 隐藏窗口不再等待网页脚本，隐藏后静音、暂停并在约 10 秒后尝试挂起 WebView2。
- 增加异步操作代次，避免快速显隐时旧暂停、直播检测或挂起结果覆盖新状态。
- 自动隐藏增加窗口边缘缓冲，按住或拖动鼠标期间不误隐藏；托盘可恢复时统一允许安全隐藏。
- 修复老板键隐藏后模态弹窗仍留在屏幕上的问题；更新提示和普通错误改为行内反馈。
- 清爽模式保持抖音原生播放器布局和互动按钮，页面结构异常时自动回退并可手动重试。
- 设置页和工具栏重新整理：窄窗口溢出菜单、可自定义/禁用四组快捷键、静音键可修改、对比度与危险操作提示优化。
- 更新下载增加超时、限长、临时文件清理、设置备份和健康启动回滚；设置备份保留最近三份。
- 修正 Windows 启动参数引用；每个架构只保留当前和最近一个旧负载目录。
- 主窗按职责拆分，新增 x64/x86 自测、冒烟、设置缩放、直播和隐藏恢复回归验证。
- 使用新的双窗口滑动＋沙发应用图标。

## 下载

- 64 位 Windows：`BoniuMoyu.exe`
- 32 位 Windows：`BoniuMoyu-x86.exe`
- 下载对应 `.sha256` 文件可核验完整性。

当前版本没有商业代码签名证书，Windows 可能显示“未知发布者”。请只从本 GitHub Release 下载并核对 SHA-256。
