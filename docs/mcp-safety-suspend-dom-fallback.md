# 紧急隐藏、后台休眠与清爽模式安全回退

- 日期：2026-09-21
- 模块：`src/MainForm.cs`

## 紧急隐藏

所有隐藏入口统一经过 `HideWindow()`：快捷键、鼠标移出、失焦、锁屏/会话断开、工具栏按钮和关闭窗口。隐藏时先同步强制 WebView2 静音，再异步暂停正在播放的视频；同时取消快捷键录入、关闭设置面板、停止直播检测，最后隐藏窗口。这样恢复时总是回到主页面，不会从设置页意外显示。

## 隐藏后自动休眠

窗口隐藏 10 秒后调用 WebView2 `TrySuspendAsync()`。挂起成功后网页脚本、视频解码与页面活动进入低资源状态。重新显示窗口或第二实例唤醒时停止延迟计时、调用 `Resume()`、恢复用户原静音状态和隐藏前正在播放的视频，并重新启动直播检测。
如果 WebView2 尚未初始化完成或暂时拒绝挂起，程序会在隐藏期间延迟重试，而不是永久放弃本次休眠。

挂起请求与显示操作存在竞态时，如果挂起完成时窗口已经显示，会立即恢复，避免窗口可见但 WebView2 仍处于挂起状态。

## 清爽模式 DOM 安全回退

清爽模式样式应用后每 1.5 秒做一次只读检查，不触发 resize，也不修改播放器或虚拟列表定位。检查当前活动 feed 和视频是否具有有效尺寸并覆盖视口中心。连续两次异常时：

1. 清空程序注入的页面样式；
2. 回退抖音原始布局，避免黑屏；
3. 停止健康检查；
4. 通过 WebView2 消息通知桌面程序，并在设置页显示“页面结构变化，已安全回退原始布局”。

页面尚未创建 video 元素时不会判定失败，避免导航加载阶段误回退。
