# 清爽模式从设置返回后黑屏修复

- 日期：2026-09-21
- 模块：`src/MainForm.cs`
- 现象：在设置中开启清爽模式，返回主页后视频区域变成黑屏。

## 根因

打开设置时程序会将 WebView2 控件设为不可见。清爽模式开关原先仍会立即执行页面样式注入，并向隐藏页面连续发送 `resize` 事件；与此同时内容区域高度从“扣除工具栏”切换为全窗口。WebView2 在不可见状态下完成这一组播放器布局变化后，返回主页没有再次应用页面布局，可能留下只有黑色容器、没有正常视频合成画面的状态。

此外，开启清爽模式会立即折叠工具栏，即使设置页仍处于打开状态，导致返回入口不稳定。

## 修复

1. `ApplyPageElementVisibility()` 在设置页打开或 WebView2 不可见时只记录延迟状态，不再向隐藏页面注入 CSS 或触发播放器重排；
2. 关闭设置、WebView2 恢复可见并置于最前后，调用 `LayoutWindow()`，再统一应用当前页面可见性和清爽模式规则；
3. 设置页打开期间不因清爽模式折叠工具栏，返回主页后再按清爽模式规则折叠。

## 验证结果

- 开启清爽模式时设置页工具栏仍可操作；
- 返回主页后才执行清爽模式 CSS 注入和播放器 resize；
- 普通的左侧导航、顶部搜索栏、右侧互动区开关同样遵循隐藏期间延迟、返回后统一应用；
- `get_diagnostics src/MainForm.cs`：0 条错误或警告；
- `scripts/build.ps1`：编译成功，生成 `dist/波妞摸鱼.exe`（1,782,784 字节）；
- `build/波妞摸鱼.Tests.exe --self-test`：25 项通过；
- `build/波妞摸鱼.Tests.exe --smoke-test`：退出码 0；
- `--settings-smoke-test` 仍返回既有的设置布局一致性失败（退出码 4）；该路径不会调用本次修改的 `ToggleSettings()`，默认也不开启清爽模式，与本次黑屏修复无代码路径关联。

真实抖音视频合成画面仍需在当前登录环境中人工复测：设置 → 开启清爽模式 → 返回主页。
