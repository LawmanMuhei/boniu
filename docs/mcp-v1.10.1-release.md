# 波妞摸鱼 v1.10.1

> 仅支持 Windows 10 / Windows 11，不支持 Windows 7、Windows 8 或 Windows 8.1。

本版本是修复版：修掉 1.10.0 里「贴边自动隐藏一旦拖过屏幕边缘就完全不生效」的问题，并新增拖动时的左右边缘吸附——窗口再也不会出现「半个身子露在屏幕外看不见」的状态。继续提供 x64 与 x86 单文件版本。

## 修复：贴边自动隐藏在冲过屏幕边缘时完全失效

1.10.0 判定"贴到了哪条边"时用的是**距离的绝对值**。后果是窗口只要越过屏幕边缘超过 16 像素，程序就认为"没贴边"——**既不收起，鼠标回到边缘也唤不出来**，窗口就那么卡在屏幕外。

而这个情况在真机上非常容易触发，因为：

> 拖动时窗口的右边缘 = 光标位置 +（窗口宽度 − 你抓标题栏的位置）。
> 窗口宽 420 像素，抓标题栏中间拖动，窗口右边缘就比光标**再多出 210 像素**；把光标拖到屏幕最右边松手，窗口已经超出屏幕 210 像素，判定直接落空。

现在改成"**贴到或越过都算贴边**"，并保留了"两侧都够近时取更近一侧"的取向。冲过头的窗口在松手时会被拉回贴齐并正常收起；就算被拖到完全看不见的地方，松手也会被救回屏幕边缘。

## 新增：拖动时左右吸附，不能再拖出屏幕

- 按住标题栏拖动，窗口靠近屏幕**左/右边缘 16 像素以内**就会贴齐过去。
- 贴齐后继续往屏幕外拖，窗口**不动**——不会再出现半个窗口在屏幕外。
- 反向往屏幕内拖**立刻跟手**，不会先黏住一小段才肯走。

实现用的是 Windows 在移动窗口时发给程序的 `WM_MOVING` 消息（`lParam` 里就是"系统打算把窗口放到哪"的矩形，允许程序修改），所以不和系统的拖动流程抢控制权，也不会抖。

**上下两侧不做限制**，窗口仍可被拖出屏幕上下边界；**缩放（拉边框改大小）也不受约束**，仍可把边拉出屏幕。这两点是有意如此，不是遗漏。

## 验证

- `--self-test` **121 项**全部通过（x64、x86），其中新增 11 项：贴边判定"冲过左右边缘仍算贴边"2 项，拖动吸附的几何与方向判定 9 项（靠近贴齐、冲出拉回、反向不黏住、只动横向、两侧同时命中取近侧、与工作区同宽时不吸附等）。
- `--regression-test` **75 项**全部通过（x64、x86），其中新增 6 项：把提案矩形真实塞进 `WM_MOVING` 的 `lParam` 发给窗口，验证冲过右/左边缘都会被拉回贴齐、离两侧都远时原样返回；再把窗口直接设到屏幕右侧外 300 像素，验证**仍能正常收起隐藏**、显式恢复能解除贴边。
- **真机手感仍需你验收**：自动化测试无法合成"真人按住鼠标拖动"，所以"系统在真实拖动时确实发送 `WM_MOVING`"属于文档行为、未在真机确认。拖到边缘应贴齐且拖不出去。

## 下载

- 手动下载（推荐）：64 位 `BoniuMoyu-1.10.1-x64.exe`，32 位 `BoniuMoyu-1.10.1-x86.exe`
- 自动更新资产：`BoniuMoyu.exe` / `BoniuMoyu-x86.exe`（程序内更新按固定文件名匹配，请勿手动下载或改名）
- 每个 EXE 附对应的 `.sha256` 校验文件；程序内自动更新同样会执行 SHA-256 校验。

## 升级说明

- 已安装 1.10.0 及更早版本：在设置中点击「检查更新」即可升级，或直接下载新 EXE 替换。
- 设置项完全不变，升级后原有的贴边自动隐藏开关、延迟等选择都会保留。
- 本版本未配置商业代码签名证书，Windows 可能显示“未知发布者”；请只从本 Release 下载并核对 SHA-256。
