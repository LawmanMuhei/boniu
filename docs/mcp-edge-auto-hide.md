# 贴边自动隐藏（Edge auto-hide）

## 需求来源

用户需求原文整理：

> 想加一个功能，可以放在设置里面开启或者不开启，用户把程序拖到屏幕的边缘，会自动隐藏程序，鼠标回到程序的边缘（隐藏后的屏幕边缘），就会出来，鼠标移出程序就隐藏了。

已确认的四项设计决定：

| 决定 | 结论 |
| --- | --- |
| 收起时视频 | 静音并暂停（复用既有老板键隐藏的媒体处理） |
| 支持的边 | 只支持屏幕**左、右**两条边 |
| 唤出触发区 | 只有**窗口原本占据的那一段**屏幕边缘，不是整条边 |
| 与现有「鼠标移出自动隐藏」 | **互斥**：开启贴边时自动接管，关闭后还原先前选择 |

补充确认：收起后任务栏与 Alt+Tab 中都不出现窗口（本程序 `ShowInTaskbar = false`，本来就是常态）。

## 交互

1. 设置 → 行为 → 打开「贴边自动隐藏」。
2. 把窗口拖到当前屏幕左/右边缘松手 → 吸附贴齐该边并收起（`Hide()`，静音并暂停视频）。
3. 鼠标回到窗口原本占据的那段屏幕边缘 → 滑回来并恢复播放。
4. 鼠标移开窗口 → 约 300ms 后再收起。
5. 把窗口拖离边缘 → 解除贴边，窗口停在用户放下的位置。

## 关键实现点

- **吸附判定**：`WM_EXITSIZEMOVE`（拖动/缩放真正结束）与 WinForms `ResizeEnd` 两处都调用 `EvaluateEdgeDock()`。只依赖 `ResizeEnd` 不够保险——它同样由这条消息派发，一旦漏发整条功能会静默失效；两处都调用是无害的，判定本身幂等。
- **阈值 16 设计像素**（`WindowRules.EdgeDockThreshold`，按 DPI 缩放）：窗口边缘距工作区边缘在此范围内即吸附。距离按 `WorkingArea` 算，因此会自动避开任务栏（含竖排任务栏）。
- **触发段**：`CalculateEdgeRevealZone` 返回贴着该侧屏幕边缘、宽 4 像素的窄带，纵向只覆盖窗口原本占据的高度并上下各留 8 像素容错。不整条屏幕边都变成热区，避免和任务栏、其他贴边程序抢区域。
- **先离开再回来**（`edgeDockRevealArmed`）：刚收起时用户的光标还停在边缘上，若不加这道闸门，窗口会在收起的下一拍立刻弹回。必须先把光标移出触发段，之后贴回边缘才唤出。
- **离开 300ms 才收起**：与「鼠标移出自动隐藏」的延迟语义一致，避免蹭边导致视频反复暂停/恢复。
- **轮询间隔**：收起后 `pointerTimer` 用 60ms（既不是常规隐藏的 250ms——碰边唤出要跟手，也不需要可见时的 100Hz）。
- **显式隐藏/恢复会解除贴边**：`HideWindow()` / `ShowWindow()` 是老板键、工具栏按钮、托盘菜单、第二个实例共用的入口，都先调用 `UndockEdge()`。用户按的是明确的隐藏/恢复命令，期望的是常规隐藏并用快捷键或托盘恢复，而不是碰边就能唤回。唯一保持贴边的是悬停唤出路径 `RevealDockedWindow()`。
- **直播横屏切换保持贴边**：`ApplyLiveLayout` / `RestorePortraitBounds` 是自动触发的，改完尺寸后调用 `RefreshEdgeDockAnchor()` 更新吸附位置与触发段。若改成解除贴边，处于收起状态的窗口会失去碰边唤回这条路。
- **迷你小窗**：`ToggleMiniMode` 若发现处于贴边状态，先 `ShowWindow()`（用户是想看窗口）再切换形态；迷你形态下不吸附。

## 互斥

`WindowRules.EffectiveMouseLeaveAutoHide(mouseLeaveEnabled, edgeAutoHideEnabled)` 是唯一判定点：贴边开启时鼠标移出隐藏一律不生效，`MonitorPointer` 用的就是它。设置界面里该项开关同时置灰（`ToggleSwitch : CheckBox`，`Enabled=false` 会画成禁用态）。

设置 `AutoHideEnabledBeforeEdge` 记住接管前的选择，关闭贴边时原样还回去；JS 序列化的老 `settings.json` 没有这两个字段，`EdgeAutoHideEnabled` 默认 false（不开启），`AutoHideEnabledBeforeEdge` 由构造函数给 true。

## 验证

- `--self-test` 新增 19 项纯逻辑用例：互斥关系、左右/过远/超阈值/两侧取近的吸附判定、贴齐坐标与纵向夹取、左右触发段几何与"未贴边无触发段"、唤出条件的三种边界（已武装且在段内 / 未武装 / 段外 / 离开屏幕边缘），以及新设置项的默认值与旧设置升级默认值。
- `--regression-test` 新增 11 项：走用户真实路径验证开关的接管与还原，再用真实窗口跑状态机（贴齐左边缘、收起、轮询间隔、立即静音、页面确实暂停、唤出并恢复播放、显式隐藏/恢复解除贴边、拖离边缘解除贴边）。
- 唤出依赖真实光标位置，无法合成，因此"贴回边缘唤出"只在自测里覆盖纯判定，**真机手感（阈值是否合适、触发段是否好命中、300ms 延迟是否舒服）需人工验收**。
