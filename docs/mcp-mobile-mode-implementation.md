# v1.11 阶段 1：可选手机版访问身份

日期：2026-10-27。依据 `mcp-mobile-mode-spike.md` 采用功能残缺分支，默认 Desktop，不迁移已有用户到 Mobile。版本统一升至 1.11.0，但未发布。

## 实现

- `SiteMode` 字符串持久化，业务使用枚举；未知值规范化为 Desktop。浏览卡片增加模式选择和真实限制说明。
- 首次导航之前完成 Android Chrome UA、Client Hints、5 触摸点、mobile 视口覆盖；主版本来自 WebView2 实际内核。Desktop 清除覆盖并恢复缓存的默认 UA。
- 不启用鼠标转触摸、不注入滚轮映射：阶段 0 已证实滚轮及方向键可以切视频，触摸上滑未切换；保留正常鼠标点击。
- Mobile 入口使用探针实际生成的主站参数；若首次导航仍落入精选，在导航完成后调用页面自身“推荐”链接一次，不伪造接口或扩大导航域名白名单。
- Mobile 不注入桌面清爽 CSS、桌面健康守卫，三个桌面隐藏开关置灰；直播布局未验收，自动横屏置灰。未找到必须隐藏的 App 遮罩，故不猜测选择器。
- 静默取消外部 App 协议；完成导航后记录 UA、mobile、触控、指针、DPR、视口及 video 尺寸，设备信号异常时校正一次。
- 渲染进程退出后重新应用配置再 Reload；浏览器进程退出后销毁旧控件、重建 WebView 再应用配置。此恢复路径是实现，尚未做真实崩溃验收。

## 验证

.NET Framework 自带 C# 5 编译通过。Client Hints 回归使用本地文件映射的 HTTPS 合成页：`NavigateToString` 的非安全上下文不提供 userAgentData，不能用于验证 Client Hints。手机信号统一、电脑信号恢复、桌面专属控件置灰均通过断言。

`check-version.ps1`：1.11.0；x64/x86 的 5 个测试入口均 exit 0，各 129 项自测、78 项合成回归通过。报告在 `artifacts/verification/tests-*.json`、`regression-*.json`。本阶段首次测试发现合成页上下文问题后改为本地 HTTPS 映射再重跑；不是忽略失败或降低断言。

未验证：真实账号 Cookie 沿用、登录操作、30 条同账号推荐统计、直播、长时间使用、真实进程崩溃恢复。不能声称手机身份获得 App 推荐或强制高清。
