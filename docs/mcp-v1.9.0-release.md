# 波妞摸鱼 v1.9.0

> 仅支持 Windows 10 / Windows 11，不支持 Windows 7、Windows 8 或 Windows 8.1。

本版本新增「迷你小窗」形态，修复清爽模式打开评论后自动退出的问题，并把顶部工具栏的悬停唤出改为贴顶触发加浮层显示；继续提供 x64 与 x86 单文件版本。

## 新增：迷你小窗

- 默认 `Ctrl + Alt + S` 进入/退出；工具栏新增迷你按钮，设置页也有开关，三者状态同步。
- 进入后缩到 340×600，按当前屏幕**工作区**停靠右下角（自动避开任务栏），最小可缩到 260×300。
- 迷你形态下可自由拖动与缩放；退出后回到进入前的形态与位置；进入前若正处于直播横屏，则恢复直播横屏尺寸。
- 迷你形态的尺寸单独记忆；若上次退出程序时正处于迷你小窗，下次启动直接以迷你形态打开。
- 快捷键可在设置中自定义，录入时按 Del 可禁用。

## 修复：清爽模式打开评论不再自动退出

- 症状：清爽模式看视频时点开评论，清爽模式自动失效，页面出现「已恢复标准布局 · 点击重试清爽样式」，需要手动再开。
- 原因：健康守卫要求播放器**覆盖视口中心**。评论面板展开时抖音会为面板腾空间，把播放器缩小或推到一侧——画面仍然完整可用，只是不再居中，于是每次采样都记一次异常，连续 3 次（约 4.5 秒）后触发闩锁式回退且不会自动重试。默认窗口只有 420×760，评论区一开，视口中心很容易落到播放器之外。
- 修复：判定改为「可见画面占视口的比例」（阈值 0.25），并在识别到抖音评论面板展开时清零计数、跳过本轮判定。
- 回退时会把实测画面比例与视口尺寸写入 `run.log`，真实页面若再出现异常可直接定位。
- 保留的安全网：把播放画面压到 10px 宽这类真实布局损坏仍会按时回退。

## 改进：顶部工具栏改为贴顶唤出，并以浮层显示

- 唤出范围由原来距顶部 **44 像素**收窄到 **6 像素**：必须几乎贴到最顶边才出来，鼠标在画面上部晃动不再误触。
- 加入迟滞：贴顶 6 像素内唤出，光标留在 44 像素内就保持，离开才收起。这样弹出后可以从容把鼠标下移到按钮上，既不会一移就收走，也不会抖动。
- 光标快速上甩越过窗口上边缘同样算贴顶，避免 100Hz 采样跳过窄带导致「甩到顶了却不出来」。
- 唤出的工具栏改为**浮层**压在画面之上，不再挤占布局高度：播放区在收起与唤出两种状态下尺寸完全相同，视频不再下移，网页也不会收到 resize 而重新排版。

## 安全：更新下载与构建供应链加固

- 更新下载校验主机名：只接受 `github.com` / `githubusercontent.com` 的 HTTPS 地址，伪装域名（如 `evilgithubusercontent.com`）会被拒绝。
- 构建时校验 WebView2 SDK 包（1.0.4191.47）的 SHA-256，解压前拦截被篡改的包。
- `publish.ps1` 支持 `-WhatIf`：只做本地构建并打印将要上传的资产、大小与哈希，不联网上传。

## 验证

- `--self-test` **91 项**全部通过（x64、x86）。
- `--regression-test` **55 项**全部通过（x64、x86），其中包含「打开评论面板不误回退」与「把播放画面压缩到 10px 宽时仍能按时回退」两类用例。
- 迷你小窗的自动化覆盖：默认快捷键、快捷键冲突、右下角停靠计算、旧设置升级默认值共 4 项自测。**窗口行为本身（进入/退出、拖动缩放、形态记忆）未做自动化测试，需人工验收。**
- 建议人工复测：迷你小窗的进出与尺寸记忆；清爽模式开评论保持开启；顶部悬停手感以及工具栏浮层是否确实盖在画面之上。

## 下载

- 手动下载（推荐）：64 位 `BoniuMoyu-1.9.0-x64.exe`，32 位 `BoniuMoyu-1.9.0-x86.exe`
- 自动更新资产：`BoniuMoyu.exe` / `BoniuMoyu-x86.exe`（程序内更新按固定文件名匹配，请勿手动下载或改名）
- 每个 EXE 附对应的 `.sha256` 校验文件；两种文件内容一致，程序内自动更新同样会执行 SHA-256 校验。

## 升级说明

- 已安装 1.8.1 及更早版本的用户：在设置中点击「检查更新」即可升级，或直接下载新 EXE 替换。
- 旧版本设置会平滑升级，新增的迷你小窗快捷键默认为 `Ctrl + Alt + S`。
- 本版本未配置商业代码签名证书，Windows 可能显示“未知发布者”；请只从本 Release 下载并核对 SHA-256。
