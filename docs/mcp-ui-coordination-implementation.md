# v1.11 阶段 4：靛紫主题与 UI 协调

日期：2026-10-27。

## 改动

- 使用方案中的深蓝灰背景、靛紫强调色、暖金更新提示、浅紫激活图标；危险操作保留红色描边。通知为深色圆角加左侧紫条，使用原生控件实色绘制，不宣称实现了 WebView 上的真实半透明。
- 工具栏左侧为状态点、后退、刷新；右侧是置顶/静音/迷你与设置/边框/隐藏/关闭两组，组间分隔线。窄窗仍折叠到更多菜单并移除分隔线。工具栏圆角 6、底部发丝线，浮层使用更亮的深色背景。
- 图标优先 Segoe Fluent Icons，回退 Segoe MDL2 Assets；字号 10.5pt。工具栏按钮共用一个 15ms Timer 驱动 120ms 背景色过渡，控件释放时从待刷新列表移除。
- 设置标题 18pt Semibold，下方复用现有 EXE 图标和版本号；卡片 12 圆角、14 内边距、12 间距、1px 描边。顺序为浏览、行为、界面、快捷键、数据与更新。
- 设置按钮可 Tab 到达，按钮、分段器、开关有焦点环；开关聚焦时环位于轨道外侧，避免紫色环在紫色轨道里不可见。快捷键录入用紫色描边，长说明被省略时有 tooltip。
- 缩放把手按 DPI 缩放。缩放通知避开已有错误/状态横幅，独立 1.2 秒消失。
- 收尾修正：手机首页遇到 SPA 的 SourceChanged 也检查“精选 → 推荐”的入口；每个导航代次至多校正一次设备配置。没有修改拖动吸附实现。

## 实际对比度

使用 sRGB 线性化后的 WCAG 相对亮度公式 `(L亮 + 0.05)/(L暗 + 0.05)` 计算；完整结果在 `artifacts/verification/ui-contrast.json`，17 个实际使用组合通过各自阈值。装饰性分隔线不按正文阈值处理。

| 组合 | 前景 / 背景 | 对比度 | 要求 |
| --- | --- | --- | --- |
| 正文 / 卡片 | F2F3F7 / 1C1E28 | 14.96 | ≥4.5 |
| 说明 / 卡片 | A4A8B8 / 1C1E28 | 7.01 | ≥4.5 |
| 说明 / 页底 | A4A8B8 / 0E0F14 | 8.09 | ≥4.5 |
| 正文 / 按钮 | F2F3F7 / 242734 | 13.39 | ≥4.5 |
| 说明 / 分段底 | A4A8B8 / 242734 | 6.27 | ≥4.5 |
| 分段选中文字 | FFFFFF / 6258DF | 5.28 | ≥4.5 |
| 激活工具栏图标 | B9B3FF / 2D2A55 | 6.96 | ≥3 |
| 关闭悬停图标 | FFFFFF / E5484D | 3.91 | ≥3 |
| 危险操作常态 / 悬停 / 按下 | FF5A5F / 242734、38232D、3E252B | 4.86 / 4.76 / 4.57 | ≥4.5 |
| 更新提示 | FFBE45 / 1C1E28 | 10.04 | ≥4.5 |
| 焦点环 / 卡片 | 7B72F0 / 1C1E28 | 4.35 | ≥3 |
| 滚动条 / 页底 | 717589 / 0E0F14 | 4.20 | ≥3 |
| 开关白色旋钮 / 开启、悬停、关闭轨道 | FFFFFF / 7B72F0、8E86F5、42485C | 3.81 / 3.05 / 9.08 | ≥3 |

方案的浅紫 Accent 7B72F0 配白色小字仅 3.81:1，因此分段选中块改用同色系 AccentPressed 6258DF，满足 4.5:1。TextTertiary 不用于正文，只用于滚动条等非文字元素。
