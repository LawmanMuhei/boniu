# 设置页返回按钮回到主页面

- 日期：2026-09-21
- 模块：`src/MainForm.cs`

## 行为

顶部操作栏的返回按钮现在根据当前界面执行不同操作：

1. 设置页打开时，点击返回会关闭设置面板、恢复 WebView2 可见，并回到原来的抖音主页面；
2. 不在设置页时，返回按钮继续执行网页历史后退；
3. 如果正在录入快捷键，返回时会先取消录入，再关闭设置；
4. 返回主页面后会重新布局窗口，并应用设置页中刚刚修改的清爽模式和页面显示选项。

该改动不会触发网页历史后退，因此从设置返回时不会离开用户原来正在观看的视频页面。
