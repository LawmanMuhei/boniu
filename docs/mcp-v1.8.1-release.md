# 波妞摸鱼 v1.8.1

> 仅支持 Windows 10 / Windows 11，不支持 Windows 7、Windows 8 或 Windows 8.1。

本版本修复清爽模式在连续下滑视频时自动退出的问题，并完整保留布局真正损坏时的安全回退能力，继续提供 x64 与 x86 单文件版本。

## 修复：清爽模式不再被误判而自动退出

- 症状：开启清爽模式后连续下滑视频，几秒后清爽模式自动失效，页面顶部出现「已恢复标准布局 · 点击重试清爽样式」，需要手动再开。
- 原因：健康检查依赖 `data-e2e="feed-active-video"` 标记。抖音推荐流是虚拟列表，滚动时该标记会被回收或改写，切换过渡帧里新旧视频都不覆盖视口中心；取样落在这个窗口内累计两次（约 1.5~3 秒）即触发安全回退，且回退后不会自动重试。
- 修复：判定改为「页面内是否存在正在渲染（可见且尺寸大于 0）并覆盖视口中心的 video」，不再依赖该标记；连续异常阈值由 2 次提高到 3 次（约 4.5 秒）；滚动、滚轮、触摸期间清零失败计数。
- 保留的安全网：页面布局真的损坏时，仍会清空注入样式、回退抖音原生布局并提示重试，只是不再被正常滚动误触发。

## 验证

- `--self-test` 69 项全部通过（x64、x86）。
- `--regression-test` 53 项全部通过（x64），其中包含「连续切换视频与设置往返不误回退」以及「把播放视频压缩到 10px 宽时仍能按时回退」两类用例。
- 建议继续人工复测：连续下滑 30 条以上视频，清爽模式应保持开启。

## 下载

- 64 位 Windows：`BoniuMoyu.exe`
- 32 位 Windows：`BoniuMoyu-x86.exe`
- 每个 EXE 附对应的 `.sha256` 校验文件；程序内自动更新同样会执行 SHA-256 校验。

## 升级说明

- 已安装 1.8.0 的用户：在设置中点击「检查更新」即可升级，或直接下载新 EXE 替换。
- 本版本未配置商业代码签名证书，Windows 可能显示“未知发布者”；请只从本 Release 下载并核对 SHA-256。
