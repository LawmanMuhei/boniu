# 波妞摸鱼 v1.10.0

> 仅支持 Windows 10 / Windows 11，不支持 Windows 7、Windows 8 或 Windows 8.1。

本版本新增「贴边自动隐藏」：把窗口拖到屏幕左/右边缘自动收起，鼠标回到那段边缘就出来，鼠标再移开又收起。设置里可开可关。继续提供 x64 与 x86 单文件版本。

## 新增：贴边自动隐藏

- 设置 → 行为 → 打开「贴边自动隐藏」，默认关闭。
- 把窗口拖到**当前屏幕的左边缘或右边缘**松手：窗口吸附贴齐那条边并收起，同时**静音并暂停视频**。
- 鼠标回到**窗口原本占据的那一段**屏幕边缘（不是整条边）：窗口滑回来并继续播放。
- 鼠标移开窗口约 0.3 秒后再次收起；不想留延迟也可以直接把它拖离边缘。
- 把窗口拖离边缘即**解除贴边**，窗口停在你放下的位置。
- 收起期间窗口不在任务栏、也不在 Alt+Tab 里；可用老板键 `Ctrl + Alt + D` 或托盘入口恢复，恢复后贴边状态解除。

设计上的几个取舍：

- **只支持左右两边。** 上边会和清爽模式的「贴顶唤出工具栏」抢同一块区域，下边通常被任务栏占着。
- **触发段只覆盖窗口原本占据的高度**（上下各留 8 像素容错），不整条屏幕边都变成热区，避免和任务栏、其他贴边程序抢区域。
- **拖动结束后 16 像素内**算贴边（按 DPI 缩放），距离按工作区计算，所以会自动避开任务栏，包括竖排任务栏。
- **鼠标离开 0.3 秒后才收起**，避免在边缘来回蹭导致视频反复暂停、恢复。

## 与「鼠标移出自动隐藏」互斥

两套逻辑都靠"鼠标离开窗口"触发，同时生效时旧的隐藏会抢先真正隐藏窗口，贴边收起和碰边唤出就永远不会发生。因此：

- 开启贴边自动隐藏时，「鼠标移出自动隐藏」会自动关闭，设置里该项**变灰**，状态显示「已由「贴边自动隐藏」接管」。
- 关闭贴边自动隐藏时，会**还原你开启之前的选择**（而不是一律打开）。

## 显式隐藏/恢复会解除贴边

老板键、工具栏的「立即隐藏」、托盘菜单、重新打开程序都属于明确的隐藏/恢复命令，执行时一并解除贴边——用户期望的是常规隐藏并用快捷键或托盘恢复，而不是碰边就能唤回。只有悬停唤出这一条路径会保持贴边。

## 其他改进

- 直播自动横屏切换、迷你小窗切换与贴边状态的交互都已处理：横屏切换会保持贴边并更新触发段；按迷你小窗快捷键时先把窗口放回来并解除贴边，再切换形态。

## 验证

- `--self-test` **110 项**全部通过（x64、x86），其中新增 19 项贴边判定：互斥关系、左右/过远/超阈值/两侧取近的吸附判定、贴齐坐标与纵向夹取、左右触发段几何、唤出条件的四种边界，以及新设置项的默认值与旧设置升级默认值。
- `--regression-test` **66 项**全部通过（x64、x86），其中新增 11 项：开关的接管与还原、设置界面确实挂上该项并正确置灰、用真实窗口跑的状态机（贴齐、收起、轮询间隔、立即静音、页面确实暂停、唤出并恢复播放、显式隐藏/恢复解除贴边、拖离边缘解除贴边）。
- **真机手感需要你验收**：16 像素吸附阈值是否顺手、那段边缘是否好命中、0.3 秒延迟是否舒服。唤出依赖真实光标位置，无法在自动化测试里合成。

## 下载

- 手动下载（推荐）：64 位 `BoniuMoyu-1.10.0-x64.exe`，32 位 `BoniuMoyu-1.10.0-x86.exe`
- 自动更新资产：`BoniuMoyu.exe` / `BoniuMoyu-x86.exe`（程序内更新按固定文件名匹配，请勿手动下载或改名）
- 每个 EXE 附对应的 `.sha256` 校验文件；程序内自动更新同样会执行 SHA-256 校验。

## 升级说明

- 已安装 1.9.0 及更早版本的用户：在设置中点击「检查更新」即可升级，或直接下载新 EXE 替换。
- 旧版本设置会平滑升级，新增的贴边自动隐藏默认**关闭**，升级后行为与之前完全一致；原有的「鼠标移出自动隐藏」设置保持不变。
- 本版本未配置商业代码签名证书，Windows 可能显示“未知发布者”；请只从本 Release 下载并核对 SHA-256。
